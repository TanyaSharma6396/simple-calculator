🧮 Simple Calculator | C++
A console-based calculator application developed using C++ that performs basic arithmetic operations.

🔍 Project Overview:
Created a simple yet functional calculator in C++ to perform addition, subtraction, multiplication, and division based on user input. The project strengthens core programming concepts like conditional statements, functions, and loops.

💡 Key Features:
Performs operations: +, -, *, /

Takes input from the user and displays results instantly

Handles invalid input and division by zero gracefully

Structured using functions for clean and reusable code

🛠️ Tools & Concepts Used:
C++ Programming Language

Functions and Control Flow (if/else, switch)

Loops and Input Validation

Basic Error Handling

📈 Outcome:
Improved understanding of C++ syntax, logical thinking, and modular code development. A great beginner-level project to practice and demonstrate programming fundamentals.
